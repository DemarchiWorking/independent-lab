# Playbook — Social Media IA (Carrossel)

> Funcionário de IA #2. Ver contexto completo em
> [`../../docs/PRODUTO-IA-FUNCIONARIOS.md`](../../docs/PRODUTO-IA-FUNCIONARIOS.md) §4.2.

| Campo | Valor |
|---|---|
| Serviço | Social Media IA (carrosséis) |
| Modelo | **Assinatura mensal** (pacote de N carrosséis/mês) |
| Categoria | marketing de conteúdo |
| Preço base (R$) | 397/mês (rascunho — validar com pricing_methodology.md) |
| Frequência | N carrosséis/mês (definir N do pacote: 4? 8?) |
| Responsável padrão | Antonio (direção) + Claude (roteiro/copy/arte) |

## 1. Escopo (o que entra / o que NÃO entra)
- Entra: roteiro, copywriting, direção de arte e geração de imagens dos
  slides, calendário de postagem sugerido.
- Não entra: gestão de tráfego pago, resposta a comentários/DMs (é outro
  serviço), fotos profissionais de produto (se o cliente não tiver banco de
  imagens).

## 2. Pré-requisitos (do cliente)
- [ ] Identidade visual básica (cores, logo) ou aprovação para criar uma
- [ ] Acesso ao Instagram/LinkedIn para agendamento (ou define quem posta)
- [ ] Brief inicial: público, tom de voz, temas recorrentes

## 3. Passo a passo da entrega
1. Brief mensal (temas do mês, datas importantes do negócio)
2. Claude gera roteiro + copy de cada carrossel
3. Geração de imagem dos slides (skill `/image`)
4. Revisão de marca (Antonio) — consistência visual
5. Entrega do pacote + calendário sugerido ao cliente

## 4. Checklist de qualidade (Definition of Done)
- [ ] Testado (legibilidade em mobile, ordem dos slides faz sentido)
- [ ] Documentado (arquivo fonte entregue, não só export final)
- [ ] Revisado contra identidade de marca do cliente
- [ ] Calendário de postagem entregue junto

## 5. SLA & métricas
- Prazo alvo: pacote do mês entregue até o dia 25 do mês anterior
- KPI de sucesso: engajamento (curtidas/comentários/salvamentos) acima da
  média histórica do cliente, quando houver histórico
- Retrabalho aceitável: 1 rodada de ajuste por carrossel

## 6. Riscos comuns & mitigação
| Risco | Mitigação |
|---|---|
| Cliente sem identidade visual definida | Oferecer mini kit de marca como add-on |
| Brief atrasado trava o mês inteiro | Prazo fixo de brief (ex.: dia 20) no contrato |
