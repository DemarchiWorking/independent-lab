> captura de referência de posicionamento salva pelo usuário junto com os
> prints do jogo, usada para ancorar o tom de "negócio regional real"
> (imobiliária) que o gamehub deve refletir.

**Elementos visuais/estruturais:**
Interface padrão do Instagram (não é o jogo) — tipografia sans-serif do
sistema, avatar com anel gradiente característico de "tem conteúdo novo",
grade 3 colunas de posts com miniaturas fixadas (pin branco no canto).
Paleta dominada por preto/branco/azul (cor do botão "Seguir"), com fotos de
imóveis de alto padrão (verde de jardim, céu, interiores claros).

**Funcionalidade / propósito desta captura:**
Não é uma tela do jogo — é uma referência de posicionamento de marca real:
a **Compass** é a maior corretora imobiliária dos EUA. O usuário guardou
este print junto aos do Startup Panic como âncora de "como uma marca
imobiliária de peso se comunica" — presença institucional forte (
"#1 Brokerage"), prova social (seguidores, imprensa), rosto de liderança
(CEO/presidente em destaque), CTA de contato direto.

**Relevância para o labdatadev-gamehub:**
Reforça que o ICP (imobiliárias regionais) responde a uma linguagem de
**autoridade + prova social + contato fácil** — não a mecânicas de jogo. Ao
desenhar a "vitrine" de cada negócio no Mapa/World (ver
[`../../world/ARQUITETURA-WORLD.md`](../../world/ARQUITETURA-WORLD.md)),
vale considerar um "cartão de visita" da sede com: nome, selo de
verificado/reputação, métricas de negócio (não de vaidade), e um CTA de
contato — o mesmo padrão que a Compass usa, em escala regional.
