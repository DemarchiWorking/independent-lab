## 5. Rollback

**Aplicação** (segundos, sem rebuild; a imagem anterior está como `:previous`):

```bash
ssh hostinger "cd /root/labdatadev-gamehub && ./deploy/docker/rollback.sh"
```

A `0040` é **aditiva** (tabela e funções novas) e a app anterior não a usa, então
voltar só a imagem é seguro. A única mudança que a app anterior sentiria é o
`insert` direto em `funcionarios_contratados`, que ela não usa (escreve por service_role).

**Banco** (só se precisar desfazer a `0040` — improvável; destrutivo para os contratos já registrados):

```sql
drop function if exists public.concluir_contrato(bigint, text, text, integer, integer, integer, smallint, smallint, smallint, smallint, smallint);
drop function if exists public.contratar_funcionario(bigint, text, integer);
drop table if exists public.contratos_concluidos;
-- as policies/grants removidos eram defesa em profundidade; para restaurar o insert direto:
-- grant insert on public.funcionarios_contratados to authenticated;
delete from _migrations.aplicadas where arquivo = '0040_contratos_e_economia.sql';
```

**Restore completo do banco** (último recurso): `./deploy/backup.sh restore deploy/backups/gamehub-20261023-234129.dump`.
O dump está **só na VPS** (`BACKUP_OFFSITE_CMD` não definido) — copie para fora se a janela de rollback importar.

## 6. Efeitos de produto que o time deve saber

- **Moeda inicial 500 → 100**, só para contas **novas**; contas existentes mantêm o saldo.
- **Contratar custa moeda** (300/400/600/900) e não paga mais prêmio. Quem já tem o
  cargo não é cobrado de novo (idempotente).
- O Documentador abre no **degrau 1**; cada contratação sobe um degrau — o que
  também libera o estúdio labdatadev (degrau mínimo) mais cedo que antes.
- Dupla contratação **simultânea** do mesmo cargo ainda pode aplicar XP/degrau duas
  vezes (a moeda é cobrada uma vez). Limitação conhecida, registrada no backlog.
