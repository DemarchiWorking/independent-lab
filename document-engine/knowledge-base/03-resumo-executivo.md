# Resumo Executivo — 1 Página, para Mostrar a um Sócio/Banco/Parceiro

## Objetivo

Diferente do "resumo executivo de 60 segundos" que já abre o Modelo de
Negócio (seção E.1 do corpus), este é um **documento autônomo**: o dono
deve poder exportar/imprimir só este arquivo e entregá-lo a alguém de fora
do jogo (sócio em potencial, gerente de banco, parceiro comercial) sem
precisar explicar o gamehub. Zero jargão de jogo (nunca mencionar XP,
degrau "do jogo", 🪙) — traduza tudo para linguagem de negócio real.

## Estrutura obrigatória (1 página, sem exceção)

```
1. Cabeçalho: nome do negócio, segmento, cidade/bairro, data
2. O que a empresa faz (2-3 frases, sem jargão, como se explicasse a um
   investidor que nunca ouviu falar do negócio)
3. Estado atual em 5 números (tabela): ex. nível de maturidade operacional
   médio (média dos 5 atributos, em %), nº de ofertas publicadas, nº de
   funcionários de IA/parcerias ativas, posição comercial atual (traduzida
   do degrau para linguagem de mercado: "fase de validação" / "fase de
   tração" / "fase de escala" — nunca "degrau X do jogo")
4. As 3 prioridades dos próximos 90 dias (não 5 — aqui é o corte editorial
   mais afiado do documento, cada uma em 1 linha, com o "porquê" em 1 linha)
5. Um risco a monitorar (o mais crítico, com plano de mitigação em 1 frase)
6. Resumo Fácil (2-3 frases finais, linguagem de leigo total)
```

## Tradução degrau → linguagem de mercado (obrigatória neste documento)

| Degrau do gamehub | Como aparece AQUI |
|---|---|
| 1 — Auditoria Digital Gratuita | Fase de diagnóstico |
| 2 — Diagnóstico Técnico | Fase de validação |
| 3 — Automação Essencial | Fase de tração inicial |
| 4 — Ecossistema Completo | Fase de crescimento |
| 5 — CTO-as-a-Service | Fase de escala regional |

## Regras de rigor

- Todo número tem fonte direta na ficha — se um dos "5 números" não tiver
  dado suficiente na ficha, substitua por outro que tenha, nunca invente.
- Nunca ultrapasse 1 página equivalente (~500-600 palavras de corpo,
  excluindo cabeçalho/tabela) — é um documento de leitura em 60 segundos por
  alguém de fora, não um relatório completo (isso já existe no Modelo de
  Negócio e no Roadmap).
- Este documento NUNCA leva a seção "Notas de Versão" — cada rodada é
  standalone (não é um documento de acompanhamento, é uma peça de
  apresentação pontual).
