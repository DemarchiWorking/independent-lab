# Proposta Comercial — Peça de Venda do TENANT para OS CLIENTES DELE

## Diferença crítica (não confundir com os outros 5 documentos)

Todos os outros documentos do gamehub são **sobre** o negócio do tenant
(diagnóstico, estratégia, plano interno). Este é diferente: é uma
**ferramenta de venda pronta para uso** que o dono do negócio leva para OS
CLIENTES DELE — ou seja, o "cliente" citado neste documento não é o
Laboratório Demarchi nem o gamehub, é quem o tenant está tentando vender
seu próprio produto/serviço.

Se a ficha não tiver nenhuma oferta publicada na vitrine (seção 5), este
documento fica genérico demais para ser útil — gere mesmo assim, mas abra
com um aviso explícito: "Nenhuma oferta cadastrada na vitrine ainda — esta
proposta usa como base [o que a ficha permitir: onboarding/segmento].
Publique uma oferta em `/vitrine` para uma proposta mais específica."

## Estrutura obrigatória

```
1. Cabeçalho: nome do negócio (o vendedor, não o comprador), segmento, data
2. Abertura — o problema do cliente-do-tenant (nomeado pelo segmento e pela
   oferta principal da vitrine, se houver)
3. A solução oferecida (baseada nas ofertas da ficha — título, descrição,
   preço já cadastrados; se preço não estiver definido, marcar
   "sob consulta", nunca inventar um valor)
4. Por que este fornecedor específico (usa como prova: atributos fortes da
   ficha traduzidos em benefício — ex. Tecnologia 28/40 → "estrutura técnica
   madura para atender com confiabilidade"; Funcionários de IA contratados →
   "equipe ampliada por IA para responder mais rápido"; parcerias regionais
   → "rede de apoio local")
5. Prova social disponível (só se a ficha der base — nº de parcerias
   formadas, tempo no jogo/mercado; se não houver prova social real na
   ficha, omitir a seção em vez de inventar depoimento)
6. Investimento e próximos passos (preço da oferta + call to action claro:
   como o cliente-do-tenant contrata)
7. Resumo Fácil
```

## Regras de rigor (mais rígidas que as demais — isto sai da mão do dono
## direto para um cliente real dele)

- **Zero número inventado.** Preço só se estiver na ficha (vitrine). Prova
  social só se houver dado real (parcerias, tempo de mercado). Nada de
  "atendemos centenas de clientes" sem essa contagem existir na ficha.
- **Zero menção a XP, degrau do jogo, 🪙 ou qualquer termo interno do
  gamehub** — este documento circula fora do jogo, para um público que nunca
  ouviu falar do labdatadev-gamehub.
- **Tom comercial direto, não consultivo** — diferente dos outros 5
  documentos (que são analíticos), este é para converter venda: frases
  curtas, benefício antes de característica, 1 call-to-action claro no
  fechamento.
- Este documento NUNCA leva "Notas de Versão" — é standalone por natureza
  (uma proposta nova a cada rodada, não um acompanhamento histórico).
